# Contributing

## Branch Naming

Use:

`task/<number>-<short-slug>`

Example:

`task/1-initial-project-setup`

## Commit Format

Use:

`type: short description`

Examples:

- `feat: add API endpoint`
- `fix: update health check`
- `test: add tests`
- `docs: update documentation`

## Pull Request Checklist

Before opening a PR:

- [ ] Tests pass
- [ ] Lint passes
- [ ] Documentation is updated if needed
- [ ] PR description explains the changes
- [ ] PR includes `Closes INT-<number>`
